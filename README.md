# Fullstack Website

A minimal full-stack website using Node.js, Express, EJS, and SQLite (better-sqlite3).

## Quick start

- Install dependencies: `npm install`
- Start the app: `npm start`
- Open: `http://localhost:3000`

## Features

- Server-rendered pages with EJS
- CRUD for posts
- Contact form stored in SQLite
- Tailwind via CDN for quick styling
